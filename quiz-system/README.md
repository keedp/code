# 答题系统 · 使用说明

纯前端单机版：双击 `index.html` 用浏览器打开就能用，不需要装任何东西、不需要联网。

## 文件

| 文件 | 作用 | 要不要改 |
| --- | --- | --- |
| `index.html` | 页面结构 | 不改 |
| `style.css` | 样式 | 不改 |
| `app.js` | 答题逻辑 | 不改 |
| `questions.js` | **题库** | **只改这个** |

## 换题：只动 questions.js

打开 `questions.js`，把示例题删掉，按下面的格式填你的真题。

### 单选题

```js
{
  type: "single",
  stem: "题干写这里",
  options: ["选项一", "选项二", "选项三", "选项四"],
  answer: "B",
  analysis: "解析（可省略）"
}
```

### 多选题

```js
{
  type: "multiple",
  stem: "题干写这里",
  options: ["选项一", "选项二", "选项三", "选项四"],
  answer: "A,C",
  analysis: "解析（可省略）"
}
```

`answer` 写成 `"A,C"`、`"AC"`、`"A C"`、`"a、c"` 都认，顺序无所谓。

### 判断题

```js
{
  type: "judge",
  stem: "题干写这里",
  answer: true,
  analysis: "解析（可省略）"
}
```

`answer` 写 `true` / `false`，或者 `"对"` / `"错"`、`"√"` / `"×"`、`"T"` / `"F"` 都认。

### 题组

题目按题组归类，答题时可以按题组筛选出题范围：

```js
window.QUIZ_BANK = [
  {
    group: "第一组 网络基础",
    questions: [
      { type: "single", stem: "...", options: [...], answer: "A" },
      { type: "judge", stem: "...", answer: true }
    ]
  },
  {
    group: "第二组 服务器配置",
    questions: [
      { type: "single", stem: "...", options: [...], answer: "C" }
    ]
  }
];
```

不写 `group` 也可以，整份题库会显示为「未分组」。

### 几个省事的地方

- **选项字母自动生成**，不用自己写 `A.`、`B.`。就算写了，系统也会自动去掉前缀。
- **不写 `type` 也能认**：`answer` 是 `true`/`false` 当判断题，含多个字母当多选题，否则当单选题。
- **答案写错了会被查出来**：点首页的「题库 / 数据」→「运行校验」，会列出第几题、错在哪。

## 功能

- 单选 / 多选 / 判断三种题型
- 练习模式（答完立刻判对错、看解析）/ 考试模式（全部答完统一交卷）
- 按题组筛选范围、自选抽题数量
- 可打乱题目顺序、可打乱选项顺序
- 答题卡跳题、上一题/下一题
- 键盘作答：`A`~`D` 或 `1`~`9` 选项，`Enter` 确认/下一题，`←` `→` 翻题
- 成绩页：得分、对错统计、逐题明细、只练错题
- 答题记录保存在本机浏览器，可导出 CSV

## 注意

- 记录存在浏览器 localStorage 里。换浏览器、换电脑、清理浏览器数据都会丢。
- 用 `file://` 双击打开时，Edge / Chrome 都正常保存记录。如果哪天换了浏览器发现记录不保存，改成用本地服务器打开即可（但一般不需要）。

## 待确认的题目

### 1. 单选（15）/ 多选（1）—— 「/home 为用户家目录」

原题问「以下对目录描述错误的是」，我给 B（`/home 为用户家目录`）。
理由：`/home` 是普通用户家目录的**父目录**，root 的家目录在 `/root`。
但若按「`/home` 是存放用户家目录的地方」理解，B 也不算错，这时可能另有答案。**这题最需要核对。**

### 2. 单选（42）—— nohup 那道题

原题题干写的是 `nohub`（应为 `nohup`），选项 A 是 `nohup pro1 2>&1 >/dev/null &`。
我选 C（`nohup pro1 >/dev/null 2>&1 &`）。A 的顺序会导致标准错误仍然输出到终端，所以 A 不满足「不想要输出和错误信息」。

### 3. 单选（6）—— `/boot` 分区大小

我给 C（`/boot 一般 50M 左右`）。实际 `/boot` 通常要 1~2G，50M 明显偏小。
但如果教材口径认为「swap 为内存 2 倍」才是错的，答案可能不同。

### 4. 多选（15）—— 麒麟 V10 默认防火墙

我给 C、D（firewalld / 动态防火墙）。这两个说法其实指同一个东西，若出题人只认其中一个，答案会变成单选。

### 5. 多选（3）—— 麒麟核心竞争力

我给 A、B、D（高安全、高可用、可定制），排除了 C「全开源」。
若教材把「全开源」也算作竞争力，则应为全选。

### 6. 判断（2）—— 删除附加组

我给「正确」。g1 只是 user01 的附加组且无其他成员，`groupdel g1` 可以成功。
若教材强调「必须先移出附加组才能删组」，则为错误。

### 7. 判断（9）—— at/cron 的 allow 与 deny

我给「正确」（allow 优先级更高）。这是 Linux 的标准行为：allow 文件存在时 deny 被忽略。
